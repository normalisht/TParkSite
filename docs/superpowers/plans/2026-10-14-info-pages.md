# Инфо-страницы: оформление и возможности

Цель — чтобы инфо-страницы (правила безопасности, политика конфиденциальности и любые другие) выглядели как
часть витрины, а не как голый текст, и администратор мог управлять видом без правки шаблонов.

Текст правил безопасности для вставки в админку — `docs/content/pravila-bezopasnosti-t-parka.md`.

## Что делаем

1. **Разделы по H2.** Текст делится на разделы по заголовкам H2 при выводе (`apps/core/rich_text.py`, без
   записи в БД: nh3 вырезает `id`, якоря ставятся на лету). Текст до первого H2 — вступление.
2. **Оформленные списки и разделы-карточки** — в оформлении «Правила»: раздел — белая карточка с номером,
   маркированный список — чек-лист с зелёными галочками.
3. **Оглавление** из H2, если разделов от трёх: на ПК — колонка справа, едет за прокруткой; на телефоне —
   сворачиваемый блок «Содержание» над текстом. Якоря — транслит заголовка (`slugify_ru`), повторы — `-2`, `-3`.
4. ~~«Обновлено ДД.ММ.ГГГГ»~~ — не делаем.
5. **Карточка «Остались вопросы?»** внизу — `partials/cta_card.html` с кнопками связи; заголовок и текст —
   «Тексты сайта» (новая страница реестра «Инфо-страницы»).
6. **Выноска «Важно»** — кнопка «Цитата» (Blockquote) в редакторе инфо-страниц; на витрине — плашка с иконкой.
7. **Таблицы** — расширение Table в редакторе инфо-страниц; на витрине — с горизонтальной прокруткой на телефоне.
8. **Подзаголовок** (`InfoPage.lead`) под H1; он же — description для поисковиков, если SEO-поле пустое.
9. **Фото в шапке** (`InfoPage.cover`): справа от заголовка на ПК, под ним на телефоне; LCP — без `lazy`,
   с `fetchpriority="high"`; оно же — `og:image`. Файл и миниатюры удаляются вместе с записью.
10. **Оформление** (`InfoPage.layout`): «Текст» (по умолчанию: разделы без карточек) / «Правила» (п. 2) /
    «Вопросы и ответы» (каждый H3 — вопрос-аккордеон `<details data-smooth>`, ответ — всё до следующего
    заголовка; H2 — группы вопросов).

Blockquote и Table включаются только у `InfoPage.body` (`INFO_HTML_EXTENSIONS`), остальные поля HTML не меняются.

## Файлы

- `apps/core/fields.py` — `INFO_HTML_EXTENSIONS`, `HtmlField(extensions=…)`.
- `apps/core/models.py` — поля `lead`, `cover` (+ спеки `cover_card`, `cover_og`), `layout`; миграция.
- `apps/core/apps.py` — `register_file_cleanup(InfoPage)`.
- `apps/core/rich_text.py` — разбор текста на вступление, разделы и вопросы.
- `apps/core/views.py` — контекст страницы, SEO с подзаголовком и фото.
- `apps/core/admin.py` — новые поля в форме, справка.
- `templates/core/info.html`, `templates/core/partials/info_*.html` — вёрстка.
- `tailwind/source.css` — `.rich-text blockquote`, `.rich-text table`, `.rich-text-rules`.
- `apps/texts/registry.py` — `Page.INFO`, тексты `info.*`; миграция с `sync_texts`.
- `templates/admin/help/sections/info-pages.html` — справка.
- Тесты: `tests/test_rich_text.py`, `tests/test_pages.py`.

## Проверка

`uv run pytest`, `uv run ruff check . && uv run ruff format --check .`, вид страницы — в браузере на ПК и
телефоне для всех трёх оформлений.
