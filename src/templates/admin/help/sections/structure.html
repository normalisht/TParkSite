Сайт собирается из нескольких разделов админки. Главная цепочка — каталог услуг:

Группа меню → Категория → Услуга
Группа — раздел меню «Услуги» в шапке и блок на главной. Категория — страница с услугами (например, «Сплавы»). Услуга — строка или карточка на странице категории; у услуги может быть своя страница.

Одна категория может входить в несколько групп, одна услуга — в несколько категорий.
